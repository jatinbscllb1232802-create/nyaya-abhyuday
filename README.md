# Nyaya Abhyuday – Techno Legal Fest

Official website for **Nyaya Abhyuday**, the Techno Legal Fest organised by the Moot Court Committee, School of Law, Forensic Justice & Policy Studies, National Forensic Sciences University (NFSU), Gandhinagar.

## Competitions

- **4th NFSU National Technological Moot Court Competition**
- **2nd NFSU National Trial Advocacy Competition**

**Dates:** 28 – 29 March 2026  
**Venue:** National Forensic Sciences University, Gandhinagar (Physical Mode)

## Features of this website

- Clean, responsive single-page design matching the brochure’s maroon & cream branding
- Sections: About, Competitions, Format overview, Timeline, Prizes, Registration & Payment, Contact
- Mobile-friendly navigation
- Ready for GitHub Pages hosting

## How to view locally

Simply open `index.html` in any modern browser, or use a local server:

```bash
npx serve .
```

## Deploy on GitHub Pages

1. Go to repository **Settings → Pages**
2. Source: Deploy from branch `main` / root
3. Your site will be live at:  
   `https://jatinbscllb1232802-create.github.io/nyaya-abhyuday/`
